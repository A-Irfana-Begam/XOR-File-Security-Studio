# XOR Security Lab | Cyber Chrome

An interactive web-based file encryption and decryption application built using Python Flask, HTML, CSS, and JavaScript.

## Features

- Encrypt `.txt` files into `.bin` files.
- Decrypt `.bin` files back into `.txt` files.
- Repeating-key XOR encryption and decryption.
- Custom encryption key input.
- Live key strength indicator.
- Show and hide encryption key.
- Drag-and-drop file upload.
- Maximum file size: 10 MB.
- Responsive interface for desktop and mobile devices.

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Vercel
